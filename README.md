# Jobbot

Бот публикует заявки в группу Max и позволяет администраторам закрывать их.

## Запуск

Установите зависимости и задайте обязательные переменные окружения:

- `MAX_BOT_TOKEN` — токен бота.
- `ADMIN_ID` — ID основного администратора.
- `GROUP_ID` — ID группы.
- `DATABASE_URL` — URL PostgreSQL, выданный хостингом.

Дополнительно можно задать:

- `ADMIN_IDS` — дополнительные ID администраторов через запятую.
- `ADMIN_LINK` — ссылка для кнопок «Беру» и «Задать вопрос».

Запустите бота командой `python bot.py`.

## Сохранение заявок

Текст заявок, их статус и ID сообщений администраторов сохраняются в PostgreSQL.
Таблица `jobs` создаётся автоматически при запуске. После перезапуска бот
сможет найти заявку по ID из кнопки закрытия и обновить её статус.

Добавьте `DATABASE_URL` в переменные окружения / Secrets хостинга и убедитесь,
что у базы есть сетевой доступ с хостинга, где работает бот. Не публикуйте URL
базы в репозитории или сообщениях.

## Оповещения о выходе участников

Бот обрабатывает событие `user_removed` для группы, указанной в `GROUP_ID`, и отправляет личное уведомление всем администраторам из `ADMIN_ID` и `ADMIN_IDS`. В сообщении указывается, покинул ли участник группу сам или был удалён администратором. Для этой функции используется текущий polling-режим; настраивать webhook не нужно.
